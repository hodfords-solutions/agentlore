Index Cursor chats (experimental) and Gemini Antigravity brain artifacts. Cursor conversations are read incrementally and read-only from Cursor's `state.vscdb` (macOS, Linux and Windows paths, `AGENTLORE_CURSOR_DIR` to override), with each chat mapped to the folder of the window it was started in. Antigravity's markdown artifacts (task lists, plans, walkthroughs) are indexed as notes (`AGENTLORE_ANTIGRAVITY_DIR` to override); its encrypted conversations are not read. The MCP `search` tool now names the supported tools and asks agents to search before grepping other repos.
