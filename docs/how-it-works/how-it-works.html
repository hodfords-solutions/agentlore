How agentlore works

Your AI coding tools already write every session to disk. agentlore reads those files, removes secrets, and keeps one local search index. Any agent can then look up what another agent learned in another repo or another tool, and only when the task needs it.

From transcripts to a shared index

  • Local onlyNo network calls and no LLM, unless you opt into semantic search or nightly consolidation. Delete ~/.agentlore and everything is gone.
  • Read-only on your toolsTranscript folders and Cursor's database are never written to.
  • Fast7.9 GB of transcripts indexed in about 15 s; a search takes 1–90 ms.
